# API Map

Generate API integration map cho một URL/screen. Output: `docs/api-map/api-map-{slug}.md`.

## When to Use

- User asks: "API map cho màn hình X", "endpoints cho /projects/zones", "map URL to APIs"
- Audit APIs cho một specific page/screen
- Onboard một URL route mới

## When NOT to Use

- Scan entire codebase → `scout` skill
- Document one specific endpoint → đọc trực tiếp

## Input

```
/an-api-map /projects/zones
/an-api-map /system/accounts
/an-api-map /projects/**
```

## Approach

Dùng **Grep/Glob/Read** trực tiếp thay vì regex scanner phức tạp. Codebase đã có cấu trúc rõ ràng, chỉ cần đọc đúng files.

## Step-by-Step

### Step 1: URL → page.tsx

```bash
# Glob tìm page file cho URL
src/app/app/{url-slug}/page.tsx
```

Ví dụ: `/projects/zones` → `src/app/app/projects/zones/page.tsx`

Nếu không tìm thấy exact, thử glob pattern.

### Step 2: page.tsx → Screen component

Đọc page.tsx, tìm default export:
```tsx
export default function ProjectZonesPage() {
  return <ZonesScreen />;  // → tên component
}
```

Sau đó resolve import path:
```tsx
import { ZonesScreen } from "@/modules/projects/screens/zones-screen";
```

### Step 3: Screen → Hooks

Đọc screen component, dùng Grep tìm:
- `useQuery(`
- `useMutation(`
- `useInfiniteQuery(`
- `use*Lookup(` hoặc `use*List(` (custom hooks)

**Quan trọng:** Không chỉ grep trực tiếp trên screen — nhiều hooks được gọi từ sub-components (vd: `<ProjectSelect>` trong ZonesScreen). Cần đọc imports và resolve sub-components.

### Step 4: Hook → Endpoint

Với mỗi hook:
1. Tìm hook definition trong `src/modules/*/hooks/`
2. Đọc body để tìm `queryFn` hoặc mutation call
3. Map đến service adapter endpoint

### Step 5: Format Output

```markdown
# API Map — {url}

> Auto-generated by `/an-api-map`
> Screen: {component} | File: {path}
> Generated: {date}

## Hooks & Endpoints

| # | Hook | Endpoint | Cache | Ghi chú |
|---|------|----------|-------|---------|

## Cross-module APIs
```

## Output Path

```
docs/api-map/api-map-{slug}.md
```

Ví dụ: `/projects/zones` → `docs/api-map/api-map-projects-zones.md`

## Example Walkthrough

Input: `/projects/zones`

1. **URL → page**: `src/app/app/projects/zones/page.tsx` exists
2. **page → screen**: `import { ZonesScreen }` from `../screens/zones-screen`
3. **screen → hooks**: Grep thấy `useZonesTreeState()`, `ProjectSelect`
4. **hooks → endpoints**: Đọc `useZonesTreeState`, tìm `useProjectsListLookup` từ `lib/query`
5. **Format**: Tạo report

## Limitations

- Hooks từ `lib/query/` (shared) được ghi nhận nhưng cần manual verify endpoint
- Nested component scanning giới hạn ở 1 level (screen → direct imports)
- Composite hooks cần expand thủ công

## Security

- Output là documentation, không executable
- Không reveal internal patterns
- Safe to commit
